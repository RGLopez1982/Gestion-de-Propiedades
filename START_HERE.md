# ⚡ INICIO RÁPIDO - 3 PASOS

## Paso 1️⃣: Descargar Node.js
- Ve a: https://nodejs.org/
- Descarga la versión **LTS** (más estable)
- Instala siguiendo los pasos

## Paso 2️⃣: Abre PowerShell en esta carpeta
- Click derecho en la carpeta del proyecto
- "Abrir en PowerShell"

## Paso 3️⃣: Ejecuta estos comandos

```powershell
npm install
npm run dev
```

## ✅ Listo!

Tu navegador abrirá automáticamente:
- **http://localhost:3000** - La aplicación

---

## 🔧 Alternativas

### Usar el script batch (más fácil)
- Doble clic en `run.bat` en esta carpeta

### Ejecutar componentes por separado

**Terminal 1 - Backend:**
```powershell
npm run server
```

**Terminal 2 - Frontend:**
```powershell
npm run client
```
